## Project Overview

A fully interactive, live web application delivering end-to-end intelligence on the UAE economy, population, smart city KPIs, jobs market and real estate — powered by Python, Streamlit and machine learning forecasting.

**This is not a static notebook. Anyone can open the live URL and explore the data interactively in their browser — no installation required.**

---

## Live Demo

Run locally:
```bash
streamlit run app.py
```

## Features

| Section | What It Does |
|---|---|
| Executive Overview | KPI cards, GDP trend, smart city progress, key insights |
| Economic Intelligence | GDP by emirate with interactive filters, pie charts |
| Population and Demographics | Population trends, nationality mix analysis |
| Smart City KPIs | Year selector, 6-metric dashboard, trend analysis |
| Jobs and Salary Intelligence | Sector comparison, salary vs volume scatter, top earners |
| Real Estate Market | Price per sqft trends, transaction volumes, market summary |
| Tech and Digital Economy | AI startups, investment surge, data jobs explosion |
| ML Forecasting Engine | Gradient Boosting forecast to 2027 with confidence bands |
| Executive Report Generator | Automated professional report generation with download |

---

## ML Methodology

The forecasting engine uses:
- Gradient Boosting Regressor
- Polynomial Feature Engineering (degree 2)
- Training data: 2015 to 2024 (10 years)
- Forecast horizon: 2025 to 2027
- Confidence band: plus/minus 5% around point estimate
